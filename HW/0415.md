# 4-21
1. Extract destination IP address D from datagram header, get network address N
2. If N is directly connected to this router, then deliver directly to host D; Otherwise, go to 3.
3. If routing table has specific host route for D, then send to the next-hop router in table; Otherwise, go to 4.
4. If routing table has route to network N, then send to the next-hop router in table; Otherwise, go to 5.
5. If routing table has default route, then send to the default router in table; Otherwise, go to 6.
6. Report forwarding error

# 4-04
- IP: Gives every device a logical address (IP address) and routes packets across different networks (best-effort delivery, no guarantee)
- ARP: Finds the MAC (physical) address that matches a given IP address on the local network
- ICMP: Sends error reports and diagnostic messages
