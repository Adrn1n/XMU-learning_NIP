# 4-40
- IGMP tells local routers which hosts join or leave a multicast group, so routers know where to send multicast data
- Tunneling is used when some networks don’t support multicast: routers wrap the multicast packet in a normal unicast packet, send it through the tunnel, and unwrap it at the other end to deliver to multiple destinations
