# 2-01
The physical layer solves the problem of sending raw bit streams (0s and 1s) across all kinds of wires, cables, or wireless links. It hides the big differences in hardware and media so the layer above it (data link layer) does not need to care. Its main features are that it defines clear rules for the connection (plug shape/size (mechanical), voltage levels (electrical), what each signal means (functional), and the order of steps (procedural)) and it turns parallel data (inside a computer) into serial data (one bit at a time on the line).

# 2-13
Channel multiplexing is used because one transmission medium (like a cable or wireless link) has limited capacity, but we often need to send many signals at the same time. It lets multiple users or data streams share the same channel efficiently, saving cost and increasing overall throughput. Common channel multiplexing technologies are: Frequency Division Multiplexing (FDM, splits the channel into different frequency bands), Time Division Multiplexing (TDM, splits the channel into different time slots), Wavelength Division Multiplexing (WDM, uses different light wavelengths (mainly for optical fiber)), Code Division Multiplexing (CDM, uses unique codes to separate signals on the same channel).
