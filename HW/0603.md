# 6-02
DNS converts domain names into IP addresses so computers can find each other on the Internet.

- Local DNS Server: First server contacted by the user; starts the lookup process
- Root DNS Server: Knows where all top-level domain (TLD) servers are
- TLD DNS Server: Manages domains under TLDs
- Authoritative DNS Server: Stores the actual IP address records for a domain and provides the final answer

# 6-05
FTP transfers files between computers using two parallel TCP connections:
1. Control connection (port 21): Always open; sends commands and responses (out-of-band control info)
2. Data connection (port 20): Opens for actual file transfer, then closes when done

Because control commands (like login, file transfer start/stop) are sent over a separate connection from the file data.

- Main server process: Listens for new client requests on port 21; starts subordinate processes
- Subordinate processes: Handle individual client requests; create data transfer processes for each file transfer

# 6-23
1. Connection Establishment:
   SMTP client (sending server) establishes a TCP connection to the SMTP server (receiving server, port 25). The server responds with `220 Service ready`.
2. Mail Transfer:
   Client sends `MAIL FROM` (sender) -> server acknowledges `250 OK`.
   Client sends one or more `RCPT TO` (recipients) -> server confirms each recipient.
   Client sends `DATA` -> server responds `354 Start mail input`.
   Client sends the message content, ending with `<CRLF>.<CRLF>`. Server responds `250 OK` after receiving the full message.
3. Connection Termination:
   Client sends `QUIT`, and the server replies `221 Service closing`, closing the TCP connection.
