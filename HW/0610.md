# 7-01
- Passive attacks (eavesdropping, traffic analysis)
- Active attacks (modification, malware, denial of service, etc.)

- Passive attack: Only listens or monitors communication without changing data (hard to detect)
- Active attack: Changes, disrupts, or fabricates data (easier to detect, more destructive)

- Encryption (protect data confidentiality)
- Authentication (verify identity of users/systems)
- Integrity checking (detect data modification)
- Access control (limit permissions)
- Firewalls (block unauthorized access)
- Intrusion detection systems (detect attacks)
- Anti-malware protection (prevent viruses/worms, etc.)

# 7-07
- Symmetric-key: Uses the same key for encryption and decryption, fast encryption and decryption, suitable for encrypting large amounts of data; High efficiency (fast), simple and widely used (e.g., DES, AES); Key distribution is difficult (both sides must securely share the same key), poor scalability (many users need many keys), cannot easily support digital signatures
- Public-key: Uses a pair of keys: public key (encryption) and private key (decryption), public key can be openly distributed, private key is kept secret; Solves key distribution problem, supports digital signatures, better scalability in open networks; Slower than symmetric encryption, more computationally expensive, not suitable for encrypting large data directly

# 7-10
1. Sender A uses private key (SKA) to sign the message -> produces a signature
2. A sends the message + signature to B
3. B uses A’s public key (PKA) to verify the signature
